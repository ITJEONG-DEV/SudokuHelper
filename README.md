# 스도쿠 도우미

스도쿠 문제를 입력하면 다음 한 단계를 힌트로 알려주는 PWA. 브라우저에서 쓰거나 휴대폰 홈 화면에 앱으로 설치할 수 있고, 설치 후에는 오프라인에서도 동작한다.

**사용하기**: https://itjeong-dev.github.io/SudokuHelper/ · 함께 쓰는 앱: [노노그램 도우미](https://itjeong-dev.github.io/NonogramHelper/) · [가쿠로 도우미](https://itjeong-dev.github.io/KakuroHelper/) · [지뢰찾기 도우미](https://itjeong-dev.github.io/MinesweeperHelper/)

## 기능

- **랜덤 문제**: 난이도(하·중·상·최상)를 골라 새 문제를 바로 푼다. 답이 하나인 문제만 내고, 난이도는 풀 때 꼭 필요한 가장 어려운 기법으로 정한다.
  - 하: 숨은 싱글·외톨이 후보만으로 풀린다. 처음 숫자 36개 이상
  - 중: 박스-줄 교차(포인팅·클레이밍)가 필요하다
  - 상: 드러난·숨은 쌍(세 쌍)이 필요하다
  - 최상: X-윙이나 그보다 어려운 추론이 필요하다. 앱이 아는 기법을 넘는 단계에서는 힌트가 그 칸의 답을 알려준다
  - 푸는 중에 `같은 난이도 한 문제 더`로 이어서 푼다
- **문제 입력**: 칸을 골라 숫자판·키보드로 입력하거나, 81자(또는 9줄) 텍스트를 붙여넣는다. 빈칸은 `0`이나 `.`으로 쓴다.
- **사진으로 입력**: 촬영하거나 고른 사진에서 판의 네 모서리를 찾고, 어긋나면 끌어서 맞춘 뒤 숫자를 읽는다. 읽기가 불확실한 칸은 주황색으로 표시되니 사진과 비교해 고친다. 사진은 기기 밖으로 보내지 않는다. 글자 인식 엔진·데이터(약 10MB)는 처음 쓸 때 CDN에서 내려받아 저장한다.
- **답 확인**: 풀기 시작할 때 답이 하나인지 검사한다. 답이 없으면 막고, 여러 개면 알린다.
- **후보수**: `후보수` 모드나 Shift+숫자로 칸마다 후보를 적는다. `후보 채우기`는 후보를 적지 않은 빈칸에 가능한 숫자를 모두 적는다.
- **단계별 힌트**: 힌트를 누를 때마다 한 단계씩 더 알려준다.
  1. 어디를 볼지 (행·열·박스 강조)
  2. 무엇을 찾을지 (기법과 숫자)
  3. 칸과 이유. `판에 적용`으로 반영한다.
- **오류 점검**: 힌트는 먼저 중복 숫자, 정답과 다른 숫자, 잘못 지운 후보, 이미 쓰인 숫자가 남은 후보를 알려준다.
- 진행 상태는 브라우저에 자동 저장된다.
- 새 버전이 배포되면 화면 아래에 새로고침 안내가 뜬다. `새로고침`을 누르면 진행 상태를 유지한 채 새 버전으로 바뀐다.

### 힌트 기법 (쉬운 순)

박스의 숨은 싱글 → 외톨이 후보 → 행·열의 숨은 싱글 → 박스-줄 교차(포인팅) → 줄-박스 교차(클레이밍) → 드러난 쌍 → 숨은 쌍 → 드러난 세 쌍 → 숨은 세 쌍 → X-윙. 모두 막히면 후보가 가장 적은 칸의 답을 알려준다.

힌트는 사용자가 적은 후보를 기준으로 찾는다. 후보를 적지 않은 칸은 계산한 후보를 쓴다.

## 키보드

| 키 | 동작 |
|---|---|
| 1~9 | 숫자 입력 (후보수 모드에서는 후보) |
| Shift+1~9 | 후보 입력 |
| Space, N | 숫자/후보수 모드 전환 |
| 방향키 | 칸 이동 |
| Tab / Shift+Tab | 다음 칸 / 이전 칸 (줄 끝에서 다음 줄로) || Backspace, Delete, 0 | 지우기 |
| H | 힌트 |
| Ctrl+Z | 실행 취소 |

## 개발

```bash
npm install
npm run dev       # 개발 서버
npm test          # 힌트 엔진 테스트
npm run build     # dist/에 PWA 빌드
npm run preview   # 빌드 결과 확인
npm run icons     # public/icon-192.png, icon-512.png 다시 만들기
```

main에 push하면 GitHub Actions(`.github/workflows/deploy.yml`)가 테스트·빌드 후 GitHub Pages에 배포한다. 빌드 결과는 상대 경로(`base: './'`)라 하위 경로에서도 동작한다.

## 구조

- `src/sudoku/board.ts`: 좌표·행·열·박스, 후보 비트마스크, 한국어 표기
- `src/sudoku/solver.ts`: 백트래킹 풀이, 답 개수 확인
- `src/sudoku/hints.ts`: 힌트 엔진 (`findHint`, `applyHint`)
- `src/sudoku/generate.ts`: 랜덤 문제 만들기 (정답 판 생성 → 점대칭으로 지우기 → 힌트 엔진으로 난이도 판정). 화면이 멈추지 않게 `generate.worker.ts`에서 돌린다
- `src/photo/image.ts`: 판 모서리 찾기, 투영 변환으로 펼치기, 칸별 숫자 모양 자르기
- `src/photo/recognize.ts`: Tesseract.js로 숫자 읽기
- `src/components/AppNav.tsx`: 퍼즐 도우미 앱 모음. 제목 줄 버튼으로 여는 시트 (네 앱에 같은 파일)
- `src/components/UpdateBanner.tsx`: 새 버전 새로고침 안내 (네 앱에 같은 파일)
- `src/components/SolvedToast.tsx`: 판 위에 겹치는 안내(다 풀었을 때 등) (네 앱에 같은 파일)
- `src/App.tsx`, `src/components/`: 화면
